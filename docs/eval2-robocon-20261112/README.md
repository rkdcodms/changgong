## 이전 안내에서 바뀐 내용

- **다음 석상으로 선행 이동 가능:** 병사 운반 후, 수동 로봇이 현재 석상을 제단으로 옮기는 동안 AutoRobot이 다음 석상 위치로 이동할 수 있다는 조교 답변이 있다. 선원 완료와 제단 배치 완료를 별도 상태로 추적한다.
- **활·핀 직접 부착:** 활은 Ithaca, 핀은 바다에 놓이며 직접 집어 오디세우스에 붙인다. 흰색 버전은 각각 자석 2개, 유색 버전은 각각 1개이므로 두 종류를 시험한다.
- **방지턱 추가:** 자동 로봇은 높이 5 × 폭 15 × 길이 135mm, 수동 로봇은 높이 16 × 폭 40 × 길이 500mm. 갑판과 물체를 적재한 상태로 시험한다.
- **히든 미션은 시작 직후 가능:** 3차 룰북 공지와 PDF 30쪽이 근거다. PDF 24쪽에 남은 3:30 문구와 충돌하므로 이 정정을 함께 읽는다. Ithaca 귀환 이후 추가 득점 불가 조건도 고려한다.
- **어두운 정지 테이프:** 현재 트랙에 어두운 마스킹 테이프를 붙일 예정이라는 답변이 있다. 기존 모두 흰색 센서 조건이 그대로 맞는지 현장에서 확인한다.
- **Eval2는 로보콘과 같은 규칙:** 현재 제한은 5분이다. Eval2 후 미션 수·시간이 조정될 수 있다는 답변을 시간 연장 확정으로 해석하지 않는다.

## 팀 코드와 구현 우선순위

확인 당시 main은 `7b5577268f9e22a7dbe6ae6a9b3a98a9b85f3a87`이었다. 작업 시작 시 최신 커밋을 다시 확인한다.

1. [Draft PR #2](https://github.com/rkdcodms/changgong/pull/2)의 카메라·인식·Mega 통합 기반을 검토한다. 확인 당시 head는 `dec2677ac176a50bdc56c9f3de085b1943d43ca6`이며, main과 별도다. 테스트 통과 보고와 실제 장비 주행 검증을 구분한다.
2. 기존 5초 자동 재출발을 시련 상태 연동으로 발전시킨다. 병사 운반 완료·제단 배치 완료·출발 공간 확보를 실제 설치 장비로 어떻게 확인할지 먼저 결정한다. 사람의 입력을 대회용 완전 자율 동작으로 간주하지 않는다.
3. 통신 끊김·카메라 실패·재시작·중복 명령·잘못된 세션에서 정지와 복구를 확인한다. 모델 신뢰도를 실측 정확도라고 표시하지 않는다.
4. 실제 정지 오차, 적재 방지턱 주행, 활·핀 파지·부착을 시험하고 5분 전체 리허설 결과로 우선순위를 정한다. 승리의 우선 조건인 Odysseus 귀환 성공 확률을 먼저 확보한다.

main의 수동 로봇 코드는 XL430 쌍 관절·XC330 그리퍼를 전제로 한다. 이전 XL330 손목·그리퍼 설계 요구와 다르므로 실제 장착 모델을 먼저 대조한다. 전압·전류·ID·영점·각도 제한을 이름만 보고 재사용하지 않는다.
