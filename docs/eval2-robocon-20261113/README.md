## 최신 Classum 답변

[132번 질문, 11/13 00:10·00:19 조교 답변](https://classum.com/main/space/254883/community/132):

- 수동 로봇으로 자동 로봇을 가로막아 멈추는 것은 가능하지만, 자동으로 동상을 감지하여 정지한 점수 **5n은 받을 수 없다**고 답변했다.
- 탈선한 자동 로봇을 밀거나 끌어 트랙으로 되돌리는 것은 가능하다고 답변했다. 이것을 모든 상황에서 리셋 감점이 면제된다는 뜻으로 확대 해석하지 않는다.
- 매니퓰레이터로 자동 로봇 버튼을 누르는 경우의 리셋 감점 여부는 **후속 공지 예정**이다. 무감점 조작·완료 신호 수단으로 확정하지 않는다.

## 이전 안내에서 반드시 고칠 부분

이전 Classum 129번의 선행 이동 허용 답변에 최신 룰북의 조건이 추가됐다. 따라서 **선원 운반 완료 → 즉시 출발** 구현은 수정해야 한다.

권장 상태 분리:

```text
목표 인식·정지
  → 필요한 선원 운반 완료
  → 석상 바닥 이탈 확인까지 정지 유지
  → 출발 공간 확보 확인
  → 다음 목표로 이동

현재 석상 제단 배치 완료는 별도로 추적
```

석상 이탈과 출발 공간 확보를 실제 센서·시야로 어떻게 확인할지 아직 정해지지 않았다면 미정으로 남긴다. 단순 5초 타이머나 임의 수동 버튼을 이 조건의 충족으로 간주하지 않는다. 이 전이표는 구현 제안이며 실제 시야와 경기 운영을 대조해 확정한다.

## 새 소프트웨어 에이전트에게 전달

이 폴더를 먼저 읽고 [기존 소프트웨어 인계서](../eval2-robocon-20261112/SOFTWARE_AGENT_HANDOFF.txt)에 다음 패치를 적용해 구현한다.

1. `eval2` 경기 설정의 시련 수를 4개로 검증하고, 일반 `robocon` 설정과 분리한다.
2. 시련 순서와 선원 수를 1분 안에 입력·검증할 수 있도록 한다.
3. `crew_done`, `statue_lifted`, `departure_clear`, `altar_done`을 독립 이벤트로 관리한다. `crew_done`만으로 정지 해제하지 않는다.
4. 석상 이탈 확인 신호가 없거나 통신이 끊기면 정지를 유지한다. 과거 시련의 지연·중복 완료 신호가 새 시련을 해제하지 않게 한다.
5. 4번째 시련 종료와 활·핀 부착·귀환·히든 미션 순서를 분리한다. 5분과 9바퀴 점수 상한을 표시하고 상대 영역 침범의 강제 복구를 고려한다.
6. 조명 있는 다크룸과 실제 적재·방지턱에서 시험한다. 임의 업로드·모터 구동 없이 모의 전이·통신 시험부터 진행한다.
