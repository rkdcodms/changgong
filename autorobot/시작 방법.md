## 기준선 (2026-11-13) — 아래 내용은 정리용으로 추가

### Mega에 올릴 펌웨어
- **`arduino/trace_stop/trace_stop.ino`** (main `7a57b60`의 `arduino_trace&stop.ino`를 위치만 옮김, SHA-256 `3575b58f…`)
- Arduino IDE: 보드 **Arduino Mega or Mega 2560**, 이 폴더를 그대로 연다.
- `arduino/vision_stop/vision_stop.ino`와 `firmware/*.hex`는 **이전 버전**이다. 올리지 않는다. (`robot_run_for robocon.py` 맨 위 설명에는 아직 `vision_stop.ino`라고 적혀 있다.)
- 업로드 전: Jetson 프로그램 종료(`Ctrl+C`), 모터 전원 OFF 또는 바퀴 띄우기.

### Jetson 코드
- Jetson `~/ced/ced_team1/autorobot`의 `jetson/`, `scripts/`가 이 브랜치와 같은지 확인:

```bash
sha256sum ~/ced/ced_team1/autorobot/jetson/robocon_control.py "$HOME/ced/ced_team1/autorobot/scripts/robot_run_for robocon.py"
```

  기대값: `a45f1213…`, `cc5bf97c…`. 다르면 Jetson에서 고친 것이므로 다시 Git에 올린다.
- `~/ced/ced_team1`은 `sgkim-pub/ced_team1` 저장소다. 그 폴더에서 `git add`/`push` 하지 않는다.

### 동작 요약
- 프로그램이 연결되면(`Q` heartbeat) **바로 출발**한다. 출발 신호에 맞춰 실행한다.
- 목표 석상이 화면에서 가장 큰 상자이고 중앙 40~60%에 3프레임·0.1초 이상 보이면 정지.
- 정지한 석상이 **화면에서 1초 연속 사라지면** 출발(룰북 29쪽: 석상을 들어 올린 뒤 출발). 수동 로봇이 측면 카메라를 1초 이상 가리면 석상이 그대로 있어도 출발하므로 가리지 않게 운전한다.
- 목표가 보이면 감속(`A`), 마지막 목표 이후에는 계속 주행.
- USB·카메라 끊김 → Mega가 1.5초 안에 FAULT 제동. 원인 확인 후 Mega RESET, 프로그램 재시작.
- 센서 8개가 모두 흰색이면 시간 제한 없이 직진한다. 첫 주행 시험에서 트랙 밖으로 나가지 않는지 확인한다.

## 팀원용 실행 절차 (2026-11-13 현장 확인)

### 1. Jetson 접속
- **무선 (Tailscale):** 노트북에 Tailscale 설치 → Jetson과 같은 tailnet 계정으로 로그인(또는 Jetson을 공유받기) → 메뉴바에서 Connected, 기기 목록에 `nvidia-desktop` 확인.

```bash
ssh nvidia@<Jetson Tailscale IP>
```

  Jetson Tailscale IP는 팀 단톡방에서 확인한다(공개 Git에 적지 않음). Jetson에서 `tailscale ip -4`로도 볼 수 있다.
- **유선 (USB-C 직결):** `ssh nvidia@192.168.55.1`
- GitHub push는 Jetson에서 비밀번호로 안 된다. 노트북에서 push한다.

### 3. 점검 → 실행

```bash
cd ~/ced/ced_team1/autorobot && /opt/hw2/venv/bin/python "scripts/robot_run_for robocon.py" --check --objects Calypso Cattle Siren
```

`Configuration and model SHA-256 verified.`가 나오면:

```bash

```

- `--objects` 뒤에는 경기 화면의 순서대로 이름: Calypso, Cattle, Cyclopes, Laestrygonians, Poseidon, Scylla, Siren, TrojanHorse
- Mega는 따로 실행하지 않는다. 전원이 켜지면 제동 상태로 기다리다가 Jetson 프로그램이 연결되는 순간 **바로 출발**한다.
- 화면: Chrome `http://<Jetson Tailscale IP>:8765/`
- 정지: 프로그램 창에서 `Ctrl+C`(Mega가 1.5초 안에 제동). 급할 때는 모터 전원 스위치.

### 4. Mega FAULT가 뜨면
화면 카드로 원인을 본다.

| 화면 | 원인 | 조치 |
|---|---|---|
| 정지 사유 없음 + 바닥 센서 "선 맞춤 필요" | 출발 순간 가운데 센서 아래에 흰 선이 없어 선 탐색 실패 | 흰 선을 센서 가운데 아래에 맞춤 |
| 통신 끊김(LINK) | USB/프로그램 끊김, 또는 실행 중 RESET | 케이블·프로그램 확인 |

복구 순서는 항상 **프로그램 `Ctrl+C` → Mega RESET → 프로그램 다시 실행**. 실행 중에 RESET을 누르면 Jetson이 Mega 재시작을 감지하고 멈춘다.

바퀴를 띄워 책상에서 시험할 때는 검은 판 위의 흰 띠(폭 2~3cm)를 센서 가운데 바로 아래(약 1cm 이내)에 둔다. 밝은 책상 위에서는 센서가 잘못 읽는다.

### 5. 현재 설정 메모
- 정지 구역은 Jetson `config/robot.local.json`에서 화면 가로 **40~90%**로 쓰고 있다(PR #2 기본 40~60%). 실제 정지 위치를 보고 조정한다.
